# ВК → Яндекс Музыка

Переносит аудиозаписи из ВКонтакте в Яндекс Музыку: ищет каждый трек, ставит лайки
(раздел «Мне нравится») и/или складывает в отдельный плейлист. Есть веб-интерфейс и консольная версия.

- «Моя музыка» целиком или любой плейлист ВК
- запасной вариант без ВК — вставить список строк `Исполнитель - Название`
- умное сопоставление: учитывает feat., скобки, ё/е, длительность, отличает ремиксы/live/slowed
- порядок «Мне нравится» сохраняется как в ВК, дубли не добавляются
- кеш поиска: можно остановить и продолжить без повторного поиска
- CSV-отчёт (открывается в Excel) — что нашлось, что нет, с какой уверенностью и ссылками

## Установка

Нужен Python 3.10+.

```bash
git clone https://github.com/Roma-novozhilov/vk2yandex.git
cd vk2yandex
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS
pip install -r requirements.txt
```

На Windows можно просто запустить `run_web.bat` — он сам создаст окружение, поставит зависимости и откроет браузер.

## Веб-интерфейс

```bash
python web/app.py
```

Открой http://127.0.0.1:5000 и пройди три шага:

1. **ВК** — вход по логину и паролю (поддерживается код подтверждения и капча), по токену или вставка списка.
2. **Яндекс** — нажми ссылку в интерфейсе, войди, скопируй адрес страницы, на которую перекинет, и вставь целиком.
3. **Перенос** — выбери лайки и/или плейлист, при желании подкрути строгость совпадения и жми «Начать».

Интерфейс слушает только `127.0.0.1`. Токены хранятся в памяти процесса и не сохраняются на диск.

## Консоль

```bash
python cli.py                              # всё спросит по ходу
python cli.py --playlist "Из ВК"           # лайки + плейлист
python cli.py --no-like --playlist "Из ВК" # только плейлист
python cli.py --vk-playlist                # взять плейлист ВК вместо «Моей музыки»
python cli.py --from-file tracks.txt       # из текстового списка
python cli.py --dry-run                    # только поиск и отчёт, ничего не добавлять
```

Чтобы не вводить токены каждый раз, скопируй `.env.example` в `.env` и заполни.
Отчёт и кеш лежат в папке `data/`.

## Где взять токены

**ВК.** Аудио-методы API ВКонтакте открыты только официальным клиентам, поэтому скрипт ходит в ВК
от имени клиента VK Android (вход по логину/паролю) или Kate Mobile (токен по
[ссылке](https://oauth.vk.com/authorize?client_id=2685278&scope=audio,offline&redirect_uri=https://oauth.vk.com/blank.html&display=page&response_type=token&revoke=1)
— после входа скопируй адрес страницы, в нём будет `access_token=...`).

**Яндекс Музыка.** Открой
[ссылку авторизации](https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d),
войди — в адресе страницы после перехода будет `access_token=...`. Вставлять можно как сам токен, так и ссылку целиком.

> Токен даёт полный доступ к аккаунту. Никому его не отправляй и не коммить `.env`.

## Если трек не нашёлся

- Открой `data/report.csv` — там видно, что было найдено лучшим кандидатом и с какой оценкой.
- Понизь строгость (`--min-score 0.55` или ползунок) и запусти ещё раз: поиск не повторяется, лучшие кандидаты
  берутся из кеша и пересчитываются по новому порогу. Чтобы искать с нуля — удали `data/match_cache.json`.
- Часть музыки из ВК (каверы, рипы, «трек без названия») в Яндексе просто отсутствует.

## Структура

```
vk2ym/
  vk.py         — получение треков из ВК (vkpymusic), парсер текстового списка
  yandex.py     — поиск, лайки, плейлисты (yandex-music)
  matcher.py    — нормализация названий и оценка совпадения
  transfer.py   — оркестрация, кеш, CSV-отчёт
web/            — Flask-приложение и страница интерфейса
cli.py          — консольная версия
tests/          — pytest
```

Тесты: `pip install pytest && pytest`.

Проект использует неофициальные API — работает, пока ВК и Яндекс их не поменяют.
